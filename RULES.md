# Development Rules

## ⚠️ CRITICAL RULES - MUST FOLLOW

### 1. Asset Viewer Updates
**EVERY TIME you generate/modify a sprite, you MUST update the asset viewer immediately.**

Steps:
1. Generate the sprite
2. Update `asset-viewer.html` to display it
3. Verify it shows correctly before considering the task complete

Never skip this step!

### 2. One Sprite at a Time
- Generate ONE sprite
- Show it in asset viewer
- Get user approval
- THEN move to next sprite

No batch generation without approval between each sprite.

### 3. Hybrid Approach (Current)
**AI-GENERATED (KEEPING):**
- Door
- Dresser
- Plant

**PROCEDURAL (for speed/control):**
- Floor
- Wallpaper
- Bed (NEW - switched from AI to procedural)
- Table
- Window
- Coffee Maker
- Rug

### 4. Stardew Valley Style Requirements
All sprites must have:
- Chunky, blocky shapes (not detailed/realistic)
- Thick 2px black outlines
- 3-5 colors maximum
- Simple, clean pixel art
- No gradients or complex shading
- Warm orange/brown color palette

### 5. Asset Viewer Labels
Use clear labels:
- `🤖 AI (KEEPING)` - AI-generated sprites we're keeping
- `⚙️ PROCEDURAL` - Code-generated sprites
- `⚙️ PROCEDURAL (NEW)` - Recently updated procedural sprites

### 6. Testing Workflow
1. Update code
2. Update asset viewer
3. Test in game
4. Get user approval
5. Document what changed
