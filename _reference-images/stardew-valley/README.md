## 💡 Stardew Valley Style Principles

Based on research, here's what makes Stardew's style distinctive:

### Visual Style:
1. **Clear Outlines** - Most objects have dark pixel outlines
2. **Warm Palette** - Browns, greens, creams, earth tones
3. **Subtle Shading** - 2-3 tone shading, gentle dithering
4. **Cozy Feel** - Inviting, comfortable, not sterile
5. **Readable** - Clear even at small scale

### Technical:
1. **Pixel Perfect** - Crisp, aligned pixels
2. **Consistent Scale** - Objects proportional to each other
3. **Top-Down View** - Slight perspective but mostly flat
4. **Textured Surfaces** - Wood grain, fabric patterns visible

### UI Design:
1. **Wooden Frames** - UI boxes look like wooden picture frames
2. **Pixel Fonts** - Custom pixel font, not system font
3. **Earth Tones** - Browns, tans, greens for UI
4. **Clear Hierarchy** - Important info stands out
