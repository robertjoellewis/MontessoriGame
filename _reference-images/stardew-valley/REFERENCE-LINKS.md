## What to Look For

### For Cottage Interior:
- **Flooring:** Wood planks, tiles, rugs
- **Walls:** Wallpaper patterns, colors
- **Furniture:** Bed, tables, chairs style
- **Decorations:** Plants, pictures, objects
- **Lighting:** How shadows/shading work
- **Perspective:** Top-down tile-based layout

### For UI Elements:
- **Text boxes:** Border style, corners, fill
- **Fonts:** Pixel font style (Stardew uses custom font)
- **Buttons:** Shape, shading, hover states
- **Bars:** Health, energy, experience bar styles
- **Icons:** Item icons, status icons
- **Menus:** Layout, spacing, organization
- **Colors:** UI color palette (browns, greens, cream)

### For Pixel Art Style:
- **Outlines:** Black or dark outlines on objects
- **Shading:** Dithering patterns, 2-3 tone shading
- **Colors:** Warm, saturated palette
- **Texture:** How materials are represented (wood grain, fabric, etc.)
- **Scale:** Consistent pixel density
