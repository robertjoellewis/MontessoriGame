## 🎨 What to Look For When Reviewing Images

### Interior Design Style:
- **Flooring:** Notice the wood plank pattern - darker lines separating planks
- **Walls:** Warm colors (beiges, tans, light browns)
- **Furniture:** Clear outlines, 2-3 tone shading
- **Objects:** Well-defined with black or dark outlines
- **Shadows:** Subtle, not harsh
- **Scale:** How big are objects relative to character?

### UI Design Patterns:
- **Borders:** Wooden frame texture on UI boxes
- **Corners:** How corners are handled (rounded? square?)
- **Text:** Font style (pixel font, readable)
- **Colors:** Earth tones - browns, greens, creams
- **Bars:** Health/energy bar design (often green with border)
- **Icons:** Clear, simple, recognizable at small size

### Color Palette:
- **Warm browns:** #8B7355, #A0826D, #6B5D52
- **Creams/beiges:** #F5E6D3, #E8D4B8
- **Greens:** #4CAF50, #8BC34A (for grass, UI accents)
- **Wood tones:** #8B6F47, #5D4037

### Technical Details:
- **Pixel density:** Objects are detailed but not cluttered
- **Outlines:** Most objects have dark pixel outlines
- **Dithering:** Gentle dithering for texture (not harsh)
- **Lighting:** Top-left light source implied

## 🔍 After Downloading - Analysis Checklist

Once you have 10-15 reference images, analyze them for:

### For Cottage Redesign:
- [ ] How is flooring textured? (wood grain pattern?)
- [ ] What colors are used for walls?
- [ ] How are furniture pieces outlined?
- [ ] What's the shadow style? (drop shadow? ambient?)
- [ ] How cluttered/clean are interiors?
- [ ] What's the perspective? (pure top-down? slight angle?)

### For UI Redesign:
- [ ] What border style do text boxes use?
- [ ] How thick are UI element borders?
- [ ] What colors are used for backgrounds?
- [ ] How is text styled? (what font, what color?)
- [ ] How are bars designed? (solid color? gradient? bordered?)
- [ ] Are corners rounded or square?
